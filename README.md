# Buddie - Roman Numeral Calculator

A beautiful calculator app that displays results in Roman numerals with an elegant blue-themed UI.

## Features

- **Roman Numeral Display**: All numbers are displayed in classic Roman numeral format
- **Dual Display**: Shows both Arabic numerals and Roman numerals simultaneously
- **Blue-Themed UI**: Beautiful gradient blue design with multiple shades
- **Basic Operations**: Addition, subtraction, multiplication, and division
- **Keyboard Support**: Use your keyboard for faster input
- **Responsive Design**: Works on desktop and mobile devices

## Roman Numerals Supported

- Numbers from 0 (NULLA) to 3999
- Negative numbers (displayed with minus sign)
- Decimal results shown as "DECIMALIS"

## Usage

Simply open `index.html` in your web browser to use the calculator.

### Button Layout

- **Number Buttons**: I, II, III, IV, V, VI, VII, VIII, IX, X, NULLA (0)
- **Operators**: +, , ×, ÷
- **Functions**:
  - C (Clear): Reset calculator
  - DEL: Delete last digit
  - = : Calculate result

### Keyboard Shortcuts

- **Numbers**: 0-9
- **Operators**: +, -, *, /
- **Calculate**: Enter or =
- **Clear**: Escape or C
- **Delete**: Backspace

## Files

- `index.html` - Main HTML structure
- `style.css` - Blue-themed styling
- `script.js` - Calculator logic and Roman numeral conversion

## Technologies

- Pure HTML5
- CSS3 with gradients and modern styling
- Vanilla JavaScript (no dependencies)
